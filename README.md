# Employee Data Analysis Using R

## Project Overview
This project analyzes fictional employee data using R.
It explores monthly salaries and years of experience
across Sales, IT, and HR departments.

## Tools Used
- R programming
- RStudio
- Data frames and summary statistics
- Data aggregation
- Data visualization using bar charts
- GitHub for project version control

## Key Analysis
- Calculated average monthly salary.
- Calculated average employee experience.
- Compared average salaries across departments.
- Created a bar chart to visualize salary differences.

## Project Files
- `employee_analysis.R` - R analysis script.
- `reports/` - Report files and salary chart.

## Skills Demonstrated
Data manipulation, descriptive statistics,
grouped analysis, visualization, and documentation.

## Data Disclaimer
The employee dataset is fictional and is intended
for learning and demonstration purposes only.# employee-data-analysis
